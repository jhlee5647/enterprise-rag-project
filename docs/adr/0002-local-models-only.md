# 평가셋 생성까지 포함해 로컬 모델만 쓴다

고객사(JUUL Labs)의 사내 문서를 다룬다고 가정하므로, 문서 내용은 어떤 경로로도 외부 API에 보내지 않는다. 답변용 LLM, 임베딩, RAGAS 평가셋 생성 모두 RunPod Pod 안의 로컬 모델(7~8B LLM을 vLLM으로 서빙)로 처리한다. 원천은 공개 아카이브라 실제 반출 위험은 낮다. 그래도 고객사 환경의 제약을 그대로 재현하는 것이 이 프로젝트의 목적이라 이 제약을 둔다.

## Consequences

- RAGAS는 구조화 출력을 여러 번 거치는데, 소형 모델에서는 실패가 잦을 수 있다. 다음 중 하나라도 해당하면 직접 만든 단순 생성기로 바꾼다: 원본 문서 ID를 되찾을 수 없을 때, 부서당 목표 문항 수를 채우지 못할 때, 검수했을 때 쓸 수 있는 질문이 절반 미만일 때.
- 평가셋 생성 모델과 답변 모델이 같으므로, 답변 모델이 자기가 만든 질문으로 평가받는 편향이 있다. 이 편향은 감수한다.
