# 트리아지 라벨

스킬들은 다섯 가지 표준 트리아지 역할(role)을 기준으로 말한다. 이 파일은 각 역할을 이 저장소 이슈 트래커의 실제 라벨 문자열에 대응시킨다.

| mattpocock/skills 라벨 | 우리 트래커 라벨    | 의미                              |
| ---------------------- | ------------------- | --------------------------------- |
| `needs-triage`         | `needs-triage`      | 메인테이너가 검토해야 함          |
| `needs-info`           | `needs-info`        | 보고자의 추가 정보를 기다리는 중  |
| `ready-for-agent`      | `ready-for-agent`   | 명세 완료, AFK 에이전트 구현 가능 |
| `ready-for-human`      | `ready-for-human`   | 사람이 직접 구현해야 함           |
| `wontfix`              | `wontfix`           | 처리하지 않음                     |

스킬이 역할을 언급하면(예: "AFK 구현 가능 트리아지 라벨을 붙여라") 이 표에서 대응하는 라벨 문자열을 사용한다.

실제로 쓰는 라벨이 다르면 "우리 트래커 라벨" 열을 수정한다.
